# UniFi Endpoint
UniFi Endpointを使ってVPNに参加する。
招待リンクが得られている場合を想定する (私がVPNの管理者になったことはないため管理者サイドは扱わない)

## Windows/macOS/iOS/Android
案内に従ってクライアントをインストールすれば良い。

## Linux
残念ながら公式クライアントがない。しかし、VPNのプロトコルがWireGuardである場合、 [Wireguard](./wireguard.md) をクライアントとして用いることができる。

なぜか、モバイルアプリ版ではWireGuard設定ファイルをエクスポートできる (Windows版でできるかは未調査)。One-Click VPNの詳細を開いて、「個人用VPNアクセス」からダウンロードできる
