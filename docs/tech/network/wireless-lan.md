# 無線LAN

## Web認証系アクセスポイント問題

!!!note
    DNS系の問題なのでtailscaleが絡んでいる可能性があるなと踏んでいる。

カフェ・ホテルなどの施設にある無線LANアクセスポイントでは、Webでの認証が存在することがある。

通常、ブラウザで適当なWebサイトにアクセスすればログインサイトが出てきて認証できる。

(おま環な気がしていて調査中だが)、私のLinux環境ではこの手の無線LANにつなぐと名前解決が死ぬ。

`cat /etc/resolve.conf` をしてアクセスポイントのIPアドレスになっている場合、以下のようなコマンドで一時的にDNSサーバーを差し替えると良い。インターフェースは `wlp3s0` となっているが、 `ip a` などで見るとよい。

```
nmcli device modify wlp3s0 ipv4.ignore-auto-dns yes ipv4.dns "1.1.1.1,8.8.8.8"
```

なお、サスペンドなどで再接続するたびにもとの設定に戻る。
